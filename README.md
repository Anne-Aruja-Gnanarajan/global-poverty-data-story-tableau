Aim: To provide a data visualisation portfolio (and story) for Australian NGOs and non-profitnorganisations to:
1. Help make strategic decisions about where to allocate resources / funding
2. Help educate potential sponsors about strategic priorities

Datasets Used
1. “Poverty and Inequality Platform” (World Bank, 2024) – data about poverty rates (by 
country/year) up to 2022
2. “World Economic Outlook” (IMF, 2024) – data about GDP and economy (by country/year) up 
to 2022

Data was manipulated into a wide table using “Knime Analytics Platform” to feed into “Tableau”.
Addressing Data Limitations: Missing values: Average of the last 5 years has been used for “recent snapshot”  visualisations to address adhoc missing values for certain years for certain countries.
